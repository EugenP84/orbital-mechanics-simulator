# Orbital Mechanics Simulator

A gamified orbital mechanics and near-Earth object simulator for introductory astrophysics education.

This application is being developed by Eugeniu Platita as an MSc Computer Science project.

## Planned technology stack

- Java 21 LTS
- JavaFX 21
- Gradle 8.13
- JUnit 5
- Git and GitHub

## Project modules

- `simulator-core` — domain model, physics engine and numerical integrators
- `simulator-data` — NASA NeoWs integration and JSON persistence
- `simulator-learning` — learning scenarios, adaptive hints and feedback
- `simulator-app` — JavaFX desktop application
- `docs` — architecture documentation, diagrams and project notes
