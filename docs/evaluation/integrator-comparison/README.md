# Numerical Integrator Comparison — Evaluation Evidence

This directory preserves the results of the formal numerical-integrator
comparison performed for the Orbital Mechanics Simulator.

## Purpose

The experiment evaluates the three numerical integration methods implemented
by the simulator:

- Forward Euler
- Velocity Verlet
- classical fourth-order Runge-Kutta (RK4)

The comparison examines:

1. maximum relative total-mechanical-energy deviation;
2. maximum trajectory error against the analytical circular two-body solution;
3. computational work measured as the number of acceleration-model evaluations.

The experiment is executed headlessly using the same numerical integration
implementations as the application.

## Experimental configuration

Each run uses the same canonical fully coupled Newtonian two-body system:

- solar-mass star;
- Earth-mass planet;
- initial separation of 1 astronomical unit;
- circular relative initial velocity;
- centre-of-mass inertial reference frame.

Every integrator starts from the same initial conditions.

The formal timestep-refinement experiment uses a fixed simulated duration of
365 days (31,536,000 seconds). The following fixed integration timesteps are
evaluated:

| Timestep | Steps |
|---|---:|
| 24 hours (86,400 s) | 365 |
| 12 hours (43,200 s) | 730 |
| 6 hours (21,600 s) | 1,460 |
| 3 hours (10,800 s) | 2,920 |
| 1 hour (3,600 s) | 8,760 |

Using 365 days ensures that every tested timestep divides the common
simulation duration exactly. No fractional final integration step or duration
adjustment is required.

This formal evaluation configuration is distinct from the interactive
comparison presented in the JavaFX application. The application comparison
uses a fixed six-hour timestep for 1,461 steps, corresponding to 365.25
simulated days.

## Measurements

### Maximum relative energy deviation

For every committed simulation state, total mechanical energy is compared
with its initial value. The reported metric is:

`max |E(t) - E(0)| / |E(0)|`

The value is dimensionless.

### Maximum trajectory error

The numerical relative position of the planet with respect to the star is
compared with the analytical circular two-body solution at the same simulated
time.

The reported value is the maximum Euclidean relative-position error observed
during the run, measured in metres.

### Acceleration evaluations

Computational work is represented by the actual number of invocations of the
acceleration model during the experiment.

For the current implementations this corresponds to:

- Forward Euler: 1 acceleration evaluation per integration step;
- Velocity Verlet: 2 acceleration evaluations per integration step;
- RK4: 4 acceleration evaluations per integration step.

This is an implementation-independent work-count metric for this comparison;
it is not a wall-clock execution-time measurement.

## Reproduction

The evidence matrix is generated by:

`IntegratorComparisonEvidenceTest`

From the project root on Windows, run:

    .\gradlew.bat :simulator-evaluation:test --tests "*IntegratorComparisonEvidenceTest" --info

The test executes all three integration methods at all five timesteps,
producing 15 observations.

## Results

The preserved output is stored in:

`results.csv`

The CSV contains the following fields:

- `integrator`
- `timestep_seconds`
- `completed_steps`
- `simulation_time_seconds`
- `max_relative_energy_deviation`
- `max_trajectory_error_metres`
- `acceleration_evaluations`

The values in `results.csv` are the outputs produced by the Java simulator
during the formal experiment; they are not independently calculated or
manually substituted reference values.

## Interpretation note

The experiment is intended to expose the different numerical characteristics
and computational costs of the three integration methods under controlled,
identical physical initial conditions.

At very small reported energy deviations, particularly for RK4 at the smaller
timesteps, floating-point numerical effects can become significant relative
to the measured deviation. Such results should therefore not be interpreted
as demonstrating unlimited improvement in energy conservation as timestep
size decreases.
